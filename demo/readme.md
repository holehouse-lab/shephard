This file contains a set of demo jupyter notebooks providing simple, well-defined examples of the types of analysis SHEPHARD makes easy.

* `01_fraction_of_PTMs_in_IDRs.ipynb` — computing the fraction of PTMs found in IDRs for a demo set of proteins.
* `uniprot/uniprot_api_examples.ipynb` — annotating proteins and proteomes directly from the UniProt REST API (domains, sites, tracks, experimental structures, and batch annotation).
